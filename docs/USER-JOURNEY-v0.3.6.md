# Shadowframe AI v0.3.6 First-Time User Journey

## 1. Download

The user lands on the release page, reads the short install steps, and downloads the full public installer bundle.

## 2. Install

The user opens `Shadowframe Setup.exe`, chooses install/data/output folders, and lets the installer complete.

During this step, Shadowframe:

- validates the local package
- installs the app
- prepares the runtime
- fetches the public model packs

## 3. Finish setup

At the end of setup, the user sees the sample prompt folders and can open them right away.

This gives them a fast “what do I type first?” starting point.

## 4. Launch Shadowframe

The user opens Shadowframe and sees:

- startup progress
- local runtime preparation
- bridge connection

Then they arrive at the main Shadowframe screen.

## 5. Home screen

On the home screen, the user:

- sees the Shadowframe branding
- understands that generation is local
- clicks **Generate Now**

## 6. Generator entry

The user reaches the creation screen and chooses a mode such as:

- Text → Image
- Image → Image
- Image → Video
- Text → Video

## 7. First generation setup

The user:

- picks a base model
- optionally selects a compatible style/LoRA
- enters a prompt or uploads an image depending on the mode

## 8. Generation state

Once they hit Generate, Shadowframe shows:

- live progress
- estimated remaining time
- a preview/output panel

## 9. First result

The user sees the generated output in the main preview area and can then:

- review it
- download it
- continue iterating

## Success condition

The first-time experience is successful if a new user can go from:

download → install → launch → open generator → run first generation

without needing to manually repair the runtime or guess where the required pieces belong.
