# Shadowframe AI v0.3.7 - What's New

Shadowframe AI v0.3.7 is the cleaned-up public Windows release.

This version makes the public install flow much simpler for first-time users: one download, one setup app, and automatic public model-pack installation during setup.

## What’s new in v0.3.7

- the public GitHub release now points users to one installer file: `Shadowframe.Setup.exe`
- public setup automatically installs Shadowframe Core
- public setup automatically downloads the required Anima, Wan, and PhotoReal packs
- public SFW sample prompts are installed automatically
- public startup keeps the launcher from falsely timing out after the local runtime is already ready
- the public setup still warns users up front if they do not have enough disk space

## Why this matters

The goal of v0.3.7 is simple:

make the public release feel like a normal Windows app install instead of a multi-file manual package handoff.

## Where to get it

- [GitHub release page](https://github.com/thebalddudeco/shadowframe-ai/releases/tag/v0.3.7)

Normal users should download `Shadowframe.Setup.exe` from that page and ignore GitHub’s automatic source-code archives.
