# Shadowframe AI brand kit

Shadowframe combines a precise framing system with cinematic ember light. The symbol is an `S` held inside four focus-frame corners: creation emerging from shadow and being brought into frame.

## Core palette

| Name | Hex | Use |
| --- | --- | --- |
| Shadow | `#09090A` | Primary background |
| Graphite | `#171719` | Panels and elevated surfaces |
| Ember | `#FF6718` | Primary brand and calls to action |
| Glow | `#FF9B55` | Highlights and gradients |
| Heat | `#E33B00` | Deep gradient endpoint |
| Porcelain | `#F7F3EF` | Primary light text |
| Fog | `#A7A7AD` | Secondary text |

## Logo rules

- Use `logo-lockup-light.svg` on black, graphite, photography, or dark gradients.
- Use `logo-lockup-dark.svg` on light backgrounds.
- Use the square mark alone below 220 px of available horizontal space.
- Keep clear space around the mark equal to one quarter of its width.
- Do not recolor, stretch, rotate, outline, or add effects to the logo.
